# Revisión diaria de cinco minutos

Una guía para conversar con una IA, ordenar tus pendientes y elegir por dónde empezar. Una pregunta por vez, sin configurar un sistema de productividad.

[Descargar ZIP](revision-diaria-5-minutos.zip?raw=true) · [Descargar .skill](revision-diaria-5-minutos.skill?raw=true)

## Cómo usarla

Descarga `revision-diaria-5-minutos.zip`. Dentro encontrarás una carpeta con `SKILL.md`, el archivo con las instrucciones.

Si tu asistente admite instalar skills, usa su opción de instalación con el formato que acepte. El ZIP también se ofrece con extensión `.skill` para los entornos que admiten ese formato. No todos los asistentes ni planes permiten instalar skills.

También puedes abrir `SKILL.md`, copiar todo su contenido en una conversación nueva con tu IA y escribir: **“Guíame con esta revisión diaria, una pregunta por vez”**. Esto utiliza las instrucciones en esa conversación; no instala una skill permanente.

## Qué obtendrás

Una prioridad, un primer paso pequeño, un momento para empezar y hasta tres apoyos si caben. La duración es orientativa y depende de tus respuestas. Puedes hacerlo hablando o escribiendo.

No necesitas conectar Notion, correo ni calendario. Si no quieres compartir un detalle, describe el pendiente de forma general.

## Privacidad

Este recurso contiene únicamente instrucciones genéricas. No incluye conversaciones, cuentas, correos, enlaces privados, bases de datos, credenciales ni tareas del creador. Descargarlo no concede acceso a sus herramientas o información.

Tus respuestas se procesan en el servicio de IA que elijas, según sus ajustes y políticas. El recurso no añade almacenamiento ni envía información por su cuenta.
